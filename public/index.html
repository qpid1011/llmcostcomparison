Methodology & Frequently Asked Questions — LLM API Pricing

1. How is the Blended $/1M token rate calculated?
Following standard industry benchmark conventions (Artificial Analysis / OpenRouter production telemetry), blended pricing weights 3 parts input tokens to 1 part output tokens: (3 × Input $/1M + 1 × Output $/1M) ÷ 4. Because RAG, coding agents, and multi-turn chat send far more prompt context than generated completion tokens, 3:1 blended cost reflects real production bills more accurately than unweighted averages.
2. How often are LLM token prices updated?
An automated GitHub Actions pipeline runs every 6 hours, cross-checking unauthenticated live catalogs from OpenRouter and LiteLLM direct provider endpoints across 25 Frontier Labs and Open-Weight Inference Clouds, archiving daily snapshots under /history/YYYY-MM-DD.json.
3. What should engineering teams verify before switching inference clouds?
Compare quantization precision (FP16/BF16 vs FP8/INT4), prompt-caching discounts, tokens-per-second throughput (Groq / Cerebras / SambaNova wafer/ASIC vs GPU clusters), rate-limit tiers, and zero-data-retention (ZDR) terms directly with each provider.
